添削返却ツール

受講者から届いた提出メールの内容を取り込み、Claude で採点したフィードバックを整形して PDF として返却します。

📘

添削手順マニュアル

  1. 受講者から自動送信されてきた 提出メール（PDF 添付） を開き、内容を確認します。
  2. 下の 「受講者情報」 セクションに名前・メールアドレス・Set番号を入力します。CC には自分（添削担当）のアドレスを入れておくと記録になります。
  3. Build a Sentence は PDF 内の「自動採点」結果をそのまま「正答数」欄に入力します（0〜10）。
  4. Write an Email セクションで：
    1. 「プロンプトをコピー」ボタン → Claude のチャットに貼り付け
    2. 続いて受講者の答案（PDF からコピー）を Claude に渡し、採点を依頼
    3. Claude が出力した JSON ブロックを「Claude 出力を貼り付け」欄にペースト
    4. 取り込む ボタンを押すと、採点・総評・修正テーブルが自動展開
    5. 必要に応じて編集（特に総評と修正コメントは人間の手を入れた方が良いことが多い）
  5. Academic Discussion も同じ手順で。
  6. 注意ポイント 欄に、次回までに意識して欲しいことを 1〜3 個書きます。
  7. 下部の PDF プレビュー で最終確認 → 問題なければ 返却メールを送信。
📑

採点 Rubric（参照用）

ETS 公式の評価観点を要約したもの。Claude プロンプトに内包されているので普段は見る必要はありませんが、スコアの最終判断に迷ったときの参照用にどうぞ。

Write an Email（0〜5）

素点採点基準
5用件を完全に達成。丁寧さ・レジスター・構成などの社会的慣習が一貫して適切。語彙構文に幅があり、誤りはほぼ時間制約由来のタイプミス程度。
4おおむね用件を達成し、伝わりやすい。慣習はほぼ適切、誤りは少数。展開はやや浅い箇所あり。
3用件は概ね達成するが、言語面の制約で明確さ・効果が損なわれる箇所あり。語形・構文・慣習に目立つ誤り。
2取り組みは見られるが大半が不十分。展開が限定的／無関係。誤りが累積し、読み取りにくい。
1用件をほぼ達成できない。断片的な英語、深刻で頻繁な誤り、原文の借用が大半。
0白紙／話題拒否／英語でない／プロンプト丸写し／無関係／無意味な打鍵。

Academic Discussion（0〜5）

素点採点基準
5議論への貢献が明確で関連性が高い。説明・例・詳細が十分に展開。構文に幅があり語選択が的確。誤りはほぼなし。
4関連性が高く、言語運用により考えが容易に伝わる。展開は適切、誤りは少数。
3概ね関連し理解可能だが、説明・例の一部が欠落／不明瞭。構文・語彙にある程度の幅。誤りが目立つ箇所あり。
2貢献の試みは見えるが、言語の制約で考えが追いにくい。展開が乏しい／部分的にしか関連しない。誤りが累積。
1有効な貢献になっておらず、言語の制約で考えがほぼ表現できていない。原文借用が大半。
0白紙／話題拒否／英語でない／プロンプト丸写し／無関係／無意味な打鍵。
Build a Sentence（自動採点 → 0〜5 換算）：10 問の並べ替えはシステムが正誤判定。正答数を ÷ 10 × 5 で 0〜5 に換算。例：7 / 10 = 3.5 / 5。
合算バンドスコア：3 タスクの 0〜5 換算平均 + 1 を 0.5 刻み四捨五入し、1.0〜6.0 にクランプ。
